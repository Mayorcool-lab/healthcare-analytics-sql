# 🏥 Healthcare Analytics SQL Project

This project demonstrates the design and use of a relational healthcare database to analyze patient demographics, medical procedures, billing performance, and physician activity. Built using Microsoft SQL Server, it simulates a small-scale data warehouse and showcases SQL skills from schema design to complex analytical queries.

## 📊 Project Objectives

- Design a normalized database schema for healthcare analytics  
- Create and manage fact and dimension tables using SQL  
- Define foreign key relationships to maintain data integrity  
- Perform multi-step data analysis to uncover operational insights  
- Answer real-world business questions using SQL aggregations, joins, and formatting

## 🔍 Key Features

- ✅ **Star schema design** (FactTable with supporting dimensions)  
- ✅ **Financial insights** (Gross Charges, Payments, Adjustments, AR, Net Collection Rate)  
- ✅ **Patient analytics** (Age segmentation, geography, visit details)  
- ✅ **Clinical reporting** (Diagnosis & CPT code performance)  
- ✅ **Payer performance** (Payment per unit by insurance type)  
- ✅ **Credentialing audit** (Impact analysis of physician credentialing delays)  

## 🛠️ Tools & Technologies

- **SQL Server** (T-SQL)  
- **SSMS** / Azure Data Studio  
- Relational Database Design  
- Data Modeling (Fact & Dimensions)  

## 📌 Sample Business Questions Solved

- Which physician specialty has the lowest net collection rate?  
- What is the average charge per patient by location?  
- How many credentialing write-offs occurred and where?  
- What is the gross collection rate by location?  
- How many CPT codes had high utilization (>100 units)?
